Armored Core pack for psprecomp — test build

This pack adds Armored Core 3 Portable, Armored Core: Silent Line Portable
and Armored Core: Last Raven Portable to psprecomp, the app that plays PSP
games recompiled to run natively. No game code or assets are included; the
app prepares each game on your computer from your own disc.

1. In psprecomp's launcher, open Packs, choose Add pack..., and choose this
   file (Armored-Core-pack.zip). It is built for your computer in a few
   seconds.
2. Choose Add game and an ISO. Keep the app open while preparation runs;
   then choose Save and play.

Supported executable versions (US PSN):
  Armored Core 3 Portable: NPUH10023 v1.01
  Armored Core: Silent Line: NPUH10025 v1.00
  Armored Core: Last Raven: NPUH10024 v1.00
Other regions, revisions, modified executables and compressed images are not
supported. An ISO with a matching ID but different executable is rejected.

Higher FPS is available for missions in all three games. On Armored Core's
Graphics page, enable Higher FPS and set FPS cap to 60 to start. Simulation
stays at 30 Hz. Menus, movies and some effects keep their original cadence.
Higher FPS is off by default; achievable rates depend on the scene and
graphics settings. See FPS.md beside this file in the pack.

The controls (scheme, controller and keyboard layouts, mouse look, deadzones,
response curve, camera smoothing) are on Armored Core's Controls page. In the
game, Escape or View + Menu opens psprecomp's menu: save states, bindings,
settings and Quit.

Moving from the earlier Armored Core Portable app: add this pack to
psprecomp. Its saves and save states are copied into psprecomp's folders,
and its prepared games come along with where their ISOs are; its settings
come in the first time the launcher shows this pack (the selected preset
becomes the settings; the others are kept, unused). Prepare each game once
with psprecomp.

This is a test build. A successful launcher startup does not by itself verify
gameplay, audio or save behavior on a particular device.
